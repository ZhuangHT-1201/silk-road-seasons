# Contributing to Silk Road Seasons

Thanks for your interest in improving the game.

## Development

1. Fork the repository and create a focused branch.
2. Run `npm start` and open `http://127.0.0.1:4173`.
3. Keep the project dependency-free unless a new dependency has a clear benefit.
4. Test at desktop and narrow mobile widths before opening a pull request.

## Historical content

Historical notes should be grounded in reliable sources. Clearly distinguish historical institutions from fictional characters and event details. When adding a source, use a complete title rather than an unsourced claim.

## Pull requests

- Explain the gameplay or historical impact of the change.
- Include screenshots for meaningful interface changes.
- Keep unrelated changes out of the same pull request.
